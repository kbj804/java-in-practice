Spring Fig 1 · 요청 한 건의 길

게시글을 쓰는 POST /posts 요청 하나가 Spring Boot 앱 안에서 어떤 상자를 거치는지 단계별로 봅니다. 아래 막대는 단계마다 Tomcat 스레드와 DB 커넥션을 쥐고 있는지 보여 줍니다.

    • 

  • 이 요청을 맡은 Tomcat 스레드
    • 

  • 빌려 쓰는 커넥션 (초록 점선 = DB로 가는 SQL, 시간 막대의 속 빈 칸 = SQL을 보낸 단계)
    • 

  • 점선 상자 = Spring이 감싼 것(JVM, 트랜잭션 프록시)
    • 



스레드는 요청이 도착할 때부터 응답할 때까지 9단계를 모두 쥐지만, 커넥션은 트랜잭션이 열린 4~8단계만 씁니다. 스레드 풀(기본 200)과 커넥션 풀(기본 10)은 따로 있어서, 둘의 크기와 쥐는 시간이 2단계 실험의 주제가 됩니다. 커넥션 3개·스레드 4개만 그렸습니다. 스페이스로 재생/멈춤, ← →로 한 단계씩 옮깁니다.
