범례

  • 왼쪽 받침 위 레인 4개 = 플랫폼 스레드 풀 newFixedThreadPool. 레인 하나 = OS 스레드 하나(1:1).
  • 오른쪽 받침 위 레인 4개 = 캐리어 스레드(ForkJoinPool) 가상 스레드를 실행해 주는 플랫폼 스레드. 기본 개수는 코어 수(이 맥은 10).
  • 레인 뒤 높은 기둥 = 스레드 스택 예약 플랫폼 스레드마다 기본 2MB(ThreadStackSize=2048K). 눈금 하나 256KB.
  • 원판과 위의 얇은 판 = 작업 하나 · 가상 스레드 얇은 판 하나가 스택 프레임 하나. 오른쪽에서는 원판이 곧 가상 스레드.
  • 힙 칸에 놓인 원판 = unmount 된 가상 스레드 스택 프레임이 힙의 stack chunk 객체로 옮겨진 상태. 필요한 만큼만 차지합니다.
  • 레인 앞 트레이 = 실행 대기 큐(FIFO) 앞 탭이 있는 칸이 머리. 빈 레인이 머리부터 가져갑니다.
  • 오른쪽 격자판 = 힙(Heap) 블로킹 중인 가상 스레드가 여기서 기다립니다.
  • 깜박이는 점 = I/O 를 기다리는 중 sleep, 소켓 읽기, DB 응답 대기.
  • 레인 앞 표시등 = 스레드가 일 없이 붙잡힘 왼쪽은 I/O 대기 중인 플랫폼 스레드, 오른쪽은 pinning 된 캐리어.
  • 원판을 두른 고리 = synchronized 모니터 이 안에서 블로킹하면 unmount 하지 못합니다(JDK 21).
  • 앞쪽 랙의 플러그 10개 = 커넥션 풀 HikariCP 기본 maximumPoolSize=10. 솟은 플러그 = 쓰는 중.
  • DB 원통 = 데이터베이스 커넥션을 쥔 가상 스레드는 쿼리 결과를 기다리는 동안 캐리어를 비웁니다.
