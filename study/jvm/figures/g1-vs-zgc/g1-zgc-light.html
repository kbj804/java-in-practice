범례

  • 바닥 타일 칸 = Region 뒤쪽 주방이 G1, 앞쪽 주방이 ZGC. 두 주방 모두 같은 크기 칸으로 나뉩니다.
  • 칸 구석 스티커 = Region 의 역할 G1 은 E(Eden)·S(Survivor)·O(Old)·H(Humongous), ZGC 는 Y(Young)·O(Old).
  • 두 칸에 걸친 큰 냄비 = Humongous 객체 Region 절반 이상 크기라 여러 칸을 연달아 차지합니다(G1).
  • 칸마다 붙은 명부 = Remembered Set 바깥 어디에서 이 칸을 가리키는지 적어 둡니다. 옮길 칸의 명부만 보면 됩니다.
  • 갠트리의 카메라 = SATB 스냅샷 표시를 시작한 순간 살아 있던 접시는 이번 사이클 동안 살아 있는 것으로 칩니다.
  • 갠트리 = 마킹과 이동 바닥을 훑으며 살아 있는 접시에 점을 찍고, 고른 칸의 접시를 옮깁니다.
  • 접시 위 점 = 마킹됨(살아 있음) 흐려진 접시는 쓰레기로 판명된 것.
  • 다이얼 = G1 멈춤 목표 기본 200ms. 이 안에 끝날 만큼만 Old 칸을 골라 섞습니다(안쪽 점 160 = 80%).
  • 주문서 꽂이 = 스레드의 Stack · GC Root
  • 끈 = 참조
  • 끈 끝 구슬 = Colored Pointer 속이 빈 구슬 = 옛 주소일 수 있음, 꽉 찬 구슬 = 확인된 새 주소.
  • 손목 검사기 = Load Barrier 끈을 당길(참조를 읽을) 때마다 구슬 색을 봅니다.
  • 펼친 장부 = Forwarding Table 옛 자리 → 새 자리 기록. 검사기가 여기서 새 주소를 찾아 끈을 다시 맵니다(self-healing).
  • 요리사 자리 정지등 = 그 요리사가 멈춤 G1 은 Stop-the-World, ZGC 는 짧은 신호 또는 Allocation Stall.
  • 앞쪽 두 줄 기록계 = 멈춤 기록 위 줄 G1, 아래 줄 ZGC. 튀어 오른 높이가 멈춘 시간.
