범례

  • 주문서 꽂이 = 스레드의 Stack · GC Root 여기서 끈을 따라 닿는 접시만 살아남습니다.
  • 끈 = 참조 주문서나 Old 접시에서 다른 접시로 이어집니다.
  • 왼쪽 배식대 = Eden 새 객체가 처음 놓이는 곳. Minor GC 때 통째로 비웁니다.
  • 배식대 레일의 탭 = 할당 위치(bump pointer) 다음 접시가 놓일 칸을 가리키며 한 칸씩 밀려갑니다.
  • 가운데 작은 선반 두 개 = Survivor S0 / S1 번갈아 쓰고 하나는 늘 비어 있습니다. 이름표에 불이 들어온 쪽이 이번 GC 의 to.
  • 접시 위 고리 = 나이(age) Minor GC 에서 살아남을 때마다 하나씩. 5개마다 진한 고리.
  • Old 접시의 흐린 뚜껑 = 승격된 뒤의 나이 고리가 날아가는 동안 그대로 따라가다가, Old 에 내려앉으면 뚜껑 하나로 눌립니다. 나이 비트는 남지만 Old 에서는 더 세지 않습니다.
  • 선반 옆 눈금 기둥과 표시 = 승격 임계값 기본 15. Survivor 가 절반 넘게 차면 내려갑니다(동적 나이 판정).
  • 오른쪽 큰 선반 = Old 임계값에 닿았거나 Survivor 에 못 들어간 접시가 옵니다.
  • Old 앞 메모판의 카드 = 카드 테이블 Old 에서 Young 을 가리키는 끈이 있는 구간의 카드가 섭니다. Minor GC 는 선 카드만 훑습니다.
  • 갠트리 = Eden 비우기 살아 있는 접시가 다 떠난 뒤 배식대를 한 번에 닦습니다.
  • 스톱워치 = 멈춘 시간(Stop-the-World) 위쪽 표시등이 켜진 동안 요리사가 멈춥니다. Minor 는 짧고 Full 은 깁니다.
